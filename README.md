# AIM · 数字大战

> 一格一行，两军对垒。这里的数字不只是大小——它们是**活的部队**，是血，是攻，是你在棋盘上指挥的每一个士兵。
>
> 一款「数字即兵种」的一维策略对战游戏。

---

## 这是什么

一张一维的地图，两端各有一座要塞。你每回合二选一：**造兵**，或者**行动**。

数字就是这个世界的一切——它同时是兵种、血量、和攻击力。数字越大越能打，但真正决定胜负的往往不是数字，而是你想清楚「这一格该往哪走、这一口该不该吞」。

谁让对面的数字和归零，谁就赢。

## 玩法速览

- **两端要塞(8)** 是产兵点，每回合能造几次兵，看你占了多少座。
- **指挥塔(9)** 是行动点，点多才能多动——所以 9 是全场最金贵的东西。
- 兵不是"造"出来的，是**在基地前一路吃一路长**的（1→2→3…），成长到 9 就到顶。
- **吞噬**能合体变大，但吞过头（>9）会爆开成两位，反而"变拉"。
- **伤害溢出**会在单位前方架一座独木桥——桥是这张地图的**地形灵魂**。
- 骑兵能跨两格；轻单位（1~3）能上桥，重装（4~7）一上桥就同归于尽。

过来，一只一只认识一下：

| 数字 | 兵种 | 一句话 |
|---|---|---|

| **2** | 斥候 | 走两格，轻装过桥，全场最灵活的斥候 |
| **3** | 弓手 | 隔着两格放冷箭 |
| **4** | 炮兵 | 隔三格轰你，重装过不去桥 |
| **5** | 重骑兵 | 冲两格，重装，撞桥同归于尽 |
| **6** | 滚木 | 自动碾过去，敌我不分的赌徒，全场最刺激 |
| **7** | 盾卫 | 近战天花板，还能给正前方挡下箭雨 |
| **8** | 要塞 | 你的产兵基地，守住它 |
| **9** | 指挥塔 | 行动点的化身，占了就是节奏 |

## 平台与技术

- **手机端（Android）** —— Flutter 打造，界面即此。
- **PC 单机版** —— Python + pygame。
- **联机** —— Node.js + Socket.io，规则引擎服务端权威判定，**三端规则逐字符一致**（手机 / 单机 / 联机玩的都是同一套规则）。
- 一维战场上，规则就是一切：三端对齐，谁都别想钻空子。

## 特色

- 一维地图，**格子随时增减**：溢出插桥（+1）、拆分（+1）、吞噬（-1）、踩桥（-2）——地图是活的。
- **数字即部队**：血、攻、兵种三位一体，成长靠吞噬，爆裂因超九。
- **桥是灵魂**：能过桥的和过不了桥的，阵容思路完全不同。
- **滚木**：把"运气"塞进纯粹数值游戏里，用它要掂量掂量。
- 全套**像素美术 + 日配语音 + 8-bit 战斗音效**，还有 9 章新手教程。

## 想玩？

- 手机端：从 **Release** 下载 APK，安装即玩。
- 自己搭：服务端 `server/`（`node src/index.js` 起联机服务），客户端在 `client/lib/core/config.dart` 里把服务器地址改成你的，`flutter build` 即可。
- PC：`pc/` 下 `start.bat` 一键跑。
