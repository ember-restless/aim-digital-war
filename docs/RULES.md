# AIM — 数字大战 规则文档

> 2026-08-11 牢大口述规则，离离整理。服务端权威计算，双端共享此规则。

## 目标

**胜利条件：敌方数字和为 0。**（敌方所有带数字的格子——含基地/指挥部——数值相加为 0）

## 地图

- 一维格线，**上限 12~16 格（偶数）**，初始只有上限的一半（6~8 格）。
- 两端分别是双方基地（8）。
- 格子数会动态增减：
  - **+1**：伤害溢出在单位前方插入独木桥（满员时不插）
  - **+1**：拆分（满员时「保大保小」，拆分方决定抹掉拆出的哪一个）
  - **-1**：吞噬合并（两格变一格）
  - **-1**：重单位踩塌独木桥（桥格删除）

## 格子内容与阵营

- 每个格子：`{ value: 0-9 | 桥, owner: p1 | p2 | 中立 }`
- 显示时我方/敌方用不同颜色区分，数值本身 0-9，独木桥是独立图标。
- **0 空地**：中立，不可操控，**不受攻击**。
- **- 独木桥**：中立地形，**不可被攻击**（符号不参与运算），本质像 0 空地（轻单位可站立/通行）。

## 数字含义（兵种表）

| 数字 | 兵种 | 备注 |
|------|------|------|
| 0 | 空地 | 中立，不可操控，不可攻击 |
| 1 | 小兵 | 攻击=1，走1格，可拆桥 |
| 2 | 轻骑兵 | 攻击=2，骑兵走2格 |
| 3 | 弓箭手 | 攻击恒1，射程2格 |
| 4 | 炮手 | 攻击恒1，射程3格 |
| 5 | 重骑兵 | 攻击=5，骑兵走2格 |
| 6 | 滚木 | 自动单位，见滚木规则 |
| 7 | 盾兵 | 攻击=7，走1格；**自身及身后单位免疫弓兵3/炮兵4远程伤害** |
| 8 | 基地 | 建筑，不可移动，提供造兵点 |
| 9 | 指挥部 | 建筑，不可移动，提供行动点 |

## 基础属性

- **血量 = 数字**。受伤害直接减：`数字 - 伤害`。
  - 减到 **0** → 变成空地。
  - 溢出为**负** → 单位不死，在它**前方（朝敌方方向）**插入一个独木桥格，数字保持原样（还是原方单位）。满员时不插。
- **攻击力**：默认 = 数字本身。**3、4 恒定 1**。
- **盾兵屏障**：弓兵(3)、炮兵(4) 的远程攻击对盾兵(7)**本体**以及**其身后**（朝己方基地方向）的友方单位**完全无效**（0 伤害，攻击行动照常消耗行动点，无提示）。判定：目标自身是 7，或目标与攻击者之间有己方盾兵 7 挡在箭路上 → 免疫。近战（1/2/5 等）、造兵 -1、滚木不受此限制。
- **射程**：3=前方2格内，4=前方3格内，其余=前方1格。
- **移动**：**只能前进（朝敌方），不能后退**。
  - 普通单位走 1 格。
  - **骑兵（2、5）固定走 2 格**，不能走 1 格；例外：前方第 2 格有数字单位（独木桥不算）时可以只走 1 格停在它面前。
  - 8、9 建筑不可移动。0、桥不可操控。
- **建筑也吃降级**：8 受 1 伤 → 7（变成可动盾兵），9 受 1 伤 → 8（变成基地）。任何数字单位都吃（0 除外）。

## 回合流程

每回合二选一：
1. **造兵**：有几个基地就造几次。每次对**任意一个基地前方一格**：
   - 空地/我方单位 → **+1**
   - 敌方单位 → **-1**（相当于攻击）
   - 独木桥 → 不能造
2. **行动**：有 n 个指挥部 → 每回合 **n+1 行动点**。每个行动耗 1 点。

## 行动（各耗 1 行动点）

1. **移动**：前进（骑兵 2 格，见移动规则）。
2. **攻击**：攻击前方射程内的敌方数字单位，造成攻击力伤害。
3. **拆分**：≥5 的单位（含 8、9）拆成两个正整数，和为原数，前后顺序自定 → 格子 +1；满员时拆分方「保大还是保小」二选一抹掉一个。
4. **吞噬**：吞**前方一格** ≤ 自身数字的单位（**敌我皆可**），合体为和 → 格子 -1。
   - 和 **超过 9** 按十进制字符拆开：10 = 「1」小兵 + 「0」空地（变拉了）。
   - 吞出 **8** = 新基地（造兵点 +1）。
   - 吞出 **9** 是唯一获得指挥部的方式（拆不出来的）：如 5 吞 4 = 9。

## 滚木（6）

- 怎么凑出 6 都行（造兵、拆分、吞噬合体）。
- 制造出来后每回合**自动前进 3 格**，不消耗行动点。
- 途径单位（第1、2格）受 **6 点伤害**。
- **第三格**如果是非建筑数字单位 → **抹杀**（直接消灭）。
- 撞到**建筑物**（8、9）→ 消失。
- 掉到**独木桥**下 → 消失（桥保留）。

## 独木桥

- 只有 **1、2、3、4** 可以通过（轻单位）。
- **5、6、7 等强行通过 → 桥塌陷**：删除该格，单位也死亡。
- **小兵 1 成功通过（到了对面）→ 桥转化为空地**（拆桥）。
- **桥上吞噬**：站在桥上的单位吞噬后**数字 ≥ 5 → 桥毁人亡**（单位死亡 + 脚下桥消失，格子变空地；与重单位踩桥塌一致）。
- 是防滚木的好手段。

## 其它

- 9 指挥部只能靠合体出来，拆不出来。
- 初始布局：两端各一个基地 8，中间全是 0 空地。
