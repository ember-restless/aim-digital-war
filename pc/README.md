# AIM 数字大战 · PC 版

像素风数字策略对战游戏（Windows）。与手机版玩法完全对齐：数字即兵力，血与攻都是数字本身。

## 怎么玩（3 步）

1. **下载** `aim-pc.zip`，解压到任意文件夹（比如 `D:\AIM`）
2. **双击 `start.bat`** —— 首次运行会自动帮你下载安装 Python 和 pygame（需要联网，约 1-2 分钟），之后每次双击就直接进游戏
3. 进入主菜单，选择模式开战！

> 如果不想用自动安装：手动装好 Python（勾选 Add to PATH），双击 start.bat 即可。

## 游戏模式

| 模式 | 说明 |
| --- | --- |
| 双人热座 | 一台电脑两人轮流操作 |
| AI·简单 | 随机出招，新手练手 |
| AI·普通 | 会攻击会合体，有来有回 |
| AI·困难 | 防守老练，会用滚木刷兵卡你走位 |

开局可选地图大小（12/14/16 格）和规则开关（滚木能否被己方攻击）。

## 基本规则

- 每个格子上的数字就是单位的**血量 = 攻击力**
- 每回合二选一：**行动**（移动/攻击/吞噬/拆分）或 **造兵**
- 攻击伤害**溢出**会在地上长出**独木桥**（1/2/3 能过桥，4/5/7 会把桥踩塌）
- **吞噬**：大数字吞小数字合体；超过 9 会拆成两个数
- **滚木 6**：每回合自动向敌方滚 3 格，前两格压伤单位，第三格直接抹杀
- 一方**无棋可走直接判负**；把对方数字总和清零即获胜

## 快捷键（电脑端）

| 按键 | 功能 |
| --- | --- |
| 鼠标 | 点击选中单位 / 点目标执行 / 点行动按钮 |
| `A` / `P` | 选择行动阶段 / 造兵阶段 |
| `1`~`9` | 选中对应数字的己方单位（再按切下一个） |
| `←` `→` | 移动选中格 |
| `↑` `↓` | 调整拆分保留值 |
| `Enter` / `空格` | 执行选中行动 / 结束回合 |
| `E` | 结束回合 |
| `M` | 对局中打开设置（音量） |
| `ESC` | 取消选中 / 返回主菜单 |

## 设置

主菜单点「设置」：BGM / 语音 / 音效 三档音量；对局中按 `M` 也能调。

## 目录结构

```
AIM-PC/
├── start.bat        ← 双击启动（自动装环境）
├── main.py          ← 主菜单
├── game_ui.py       ← 对局界面
├── rules.py         ← 规则引擎（与手机版/服务器逐行对齐）

├── audio.py         ← 8bit 音效合成 + 语音 + BGM
├── fonts/           ← 中文字体（文泉驿微米黑）
└── assets/audio/    ← 战斗语音（日配）/ BGM
```

## 常见问题

- **双击没反应**：先确认联网；start.bat 首次要下载 Python，等 1-2 分钟别关窗口
- **报错 pygame 装不上**：重开一次 start.bat 重试；还不行就手动装 Python 后重试
- **没声音**：检查系统音量；设置里把 BGM/语音/音效音量调大
- **游戏窗口太大/太小**：窗口固定 1280×720，请把系统显示缩放设为 100% 或调小窗口模式
